package pl.cbr.notebook.ui.swing;

import lombok.Getter;
import lombok.RequiredArgsConstructor;

import javax.swing.text.SimpleAttributeSet;

@RequiredArgsConstructor(staticName = "of")
@Getter
public class CodeBlock implements Comparable<CodeBlock> {
    private final Integer id;
    private final String regExp;
    private final SimpleAttributeSet style;

    @Override
    public int compareTo(CodeBlock codeBlock) {
        return codeBlock.getId().compareTo(getId());
    }
}

**Listy i numerowanie**

Umieszczajac na pozycjach od 0 do 5 cyfry, litery zakończone kropa lub ) i spacja automatycznie robimy listę.
To oznacza, że numeracja listy automatycznie się pogrubia

**Linki**

1. Zewnętrzne
umieszczając w teście prawidłowy link np
https://www.wp.pl
automatycznie umieszczamy go na liście linków.
Klikając na niego na stronie automatynie przechodzimy do tej strony w standardowej przeglądarce

2. Wewnętrzne
można umieścić link do innej notatki wpisując jej tytuł w podwójnym nawiasie
((TST1))
Kliknięcie na takiego linka automatycznie przeniesie nas do tej notatki
